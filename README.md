# NEXO TECH STUDIOS · sitio web

Sitio estático publicado con **GitHub Pages** en https://nexotechstudios.com

## Cómo hacer cambios
1. Edita los archivos de esta carpeta (`index.html`, `proyectos/…`, etc.).
2. En GitHub Desktop escribe un resumen del cambio y presiona **Commit to main**.
3. Presiona **Push origin**. En 1 o 2 minutos el cambio está en línea.

## Archivos importantes
- `CNAME`: el dominio del sitio. No lo borres.
- `og-image.jpg`: imagen que aparece al compartir el enlace.
- `legal.css` / `legal.js`: estilos de las páginas legales y de la 404.
- `sitemap.xml` / `robots.txt`: ayudan a Google a encontrar las páginas.
